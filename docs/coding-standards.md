Every controller must:

- Be under 200 lines.
- Use FormRequest validation.
- Never contain HTML.
- Never contain SQL.
- Use Services.

Every Blade:

- Use Components.
- No duplicated HTML.

- Define relationships.
- Use casts.
- Use scopes where appropriate.

Every Migration:

- Reversible.
- Indexed.
- Foreign keys.

Every Feature:

- Have success/error handling.
- Flash messages.
- Validation.
- Authorization.
